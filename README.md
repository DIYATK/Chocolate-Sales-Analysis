## Chocolate Sales Analysis – Power BI Dashboard

### Project Overview

This project focuses on analyzing chocolate sales performance across products, countries, sales persons and dates.

### Tools Used
- Power BI
- Power Query
- Data Visualization

### Key Insights
- Analyzed sales performance across different chocolate products.
- Compared sales across different countries.
- Analyzed sales performance of sales persons.
- Used date-wise analysis to understand sales trends.
- Identified top-performing products and sales persons.

### Dashboard
Created an interactive Power BI dashboard using KPI cards, bar chart, line chart and donut chart with Country, Product and Date slicers.
